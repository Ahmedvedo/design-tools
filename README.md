## 📋 About design-tools

design-tools is software made to help you create and manage visual designs on Unix-like systems. It includes tools for working with colors, themes, and desktop elements. The toolset supports various common design workflows, such as generating themes for GTK and GRUB. It helps you organize your workspace and automate repetitive design tasks.

This package focuses on providing practical tools you can use in a desktop environment that supports GNOME or similar setups. It also works well with editors like VSCode to improve your design workflow.
